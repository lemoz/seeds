# Seeds - Project Concept

## Vision

Seeds are workflow-outcome prompts that enable anyone with Claude Code or Codex to deploy and tailor open source software for their specific profession and situation in hours, not weeks.

## Core Principle

**Workflows, not features. Outcomes, not tools.**

Instead of "deploy Metabase" → "I need to see which customers are about to churn"
Instead of "set up a booking system" → "I need clients to self-schedule without back-and-forth"

## What a Seed Does

1. **Identifies the right OSS** - explains why this tool for this outcome
2. **Deploys it** - Docker, Railway, VPS, whatever fits
3. **Tailors it** - customizes for their specific workflow
4. **Integrates it** - connects to their existing tools
5. **Documents it** - so they can maintain it

## Target Audience

Anyone capable of running Claude Code or Codex. The seed removes:
- "What should I build?" → We give them the idea
- "How do I describe it?" → We give them the prompt
- "Will this work?" → We validate the approach

## Approach

1. Map professions systematically
2. Identify workflows per profession (10-30 each)
3. Score workflows against rubric
4. Build seeds for top 1000 workflows
5. Create searchable catalog

## Success Metrics

- 1000+ seeds published
- 50+ professions covered
- 2000+ workflows mapped
