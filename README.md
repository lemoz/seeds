# Seeds

Workflow-outcome prompts that deploy and tailor OSS for specific professions.

## Concept

A **Seed** is a prompt + context that enables anyone with Claude Code or Codex to deploy a tailored open source solution for their specific workflow in hours.

**Think outcomes, not tools:**
- Not "deploy Metabase" → "I need to see which customers are about to churn"
- Not "set up booking" → "I need clients to self-schedule without back-and-forth"

## Structure

```
seeds/
├── seeds/              # Published seeds by profession
├── professions/        # Profession workflow mappings
├── rubric/             # Scoring criteria
├── docs/               # Project documentation
└── work_orders/        # Project work tracking
```
